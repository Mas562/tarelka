# Тарелка 2.3.2 — голосовой ввод продуктов

В «Что приготовить → Продиктовать продукты» появилось отдельное окно с объёмным голубым кругом. При включённом микрофоне круг плавно движется и реагирует на громкость. Распознанный список всегда виден. Есть «Пауза», «Продолжить», «Готово» и закрытие с сохранением уже записанного текста.

Микрофон включается кнопкой «Начать диктовку». Одна сессия длится до минуты; продолжение добавляет новые продукты к существующим. Закрытие окна останавливает микрофон. Аудио не сохраняется и не отправляется в облако.

Распознанные фразы теперь накапливаются. Новая фраза после паузы не заменяет предыдущие продукты. Промежуточные результаты одной фразы исправляются на месте, без повторного добавления каждого слова. Учитываются временные отметки фраз и перезапуск системного распознавания.

Анимация ограничена небольшим кругом и останавливается вместе с микрофоном. Уровень звука обновляется отдельно от формы продуктов. Настройка macOS «Уменьшение движения» отключает движение круга.

## Проверки

92 автоматических теста прошли, включая новые сценарии: «картошка → пауза → яйцо», исправление текущей фразы, повтор одного продукта после паузы, изменение пунктуации, сброс временных отметок и перезапуск распознавания. Это проверка обработки результатов, а не точности распознавания реального голоса. Проверка с живым микрофоном пока не выполнена.

В отдельной тестовой копии проверены открытие голосового окна, отображение списка «Картошка, два яйца, сыр» и закрытие кнопкой «Готово»: текст остаётся в поле продуктов. Личный дневник не изменялся.
