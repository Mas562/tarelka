# Тарелка 2.3.1 — нагрузка помощника

- Ввод сожжённых калорий, изменение дневника и профиля больше не вызывают генерацию. Калории и БЖУ пересчитываются сразу обычными формулами.
- Совет запускается только по кнопке. Повторные нажатия во время ответа не создают новых запросов.
- Для текста используется отдельная Qwen3 4B Instruct: два потока CPU, без GPU, контекст 6144, максимум 1000 токенов ответа. Модель для фото не менялась.
- После ответа модель освобождает память. «Отмена» отменяет сетевой запрос; уход с экранов дня/помощника также отменяет работу.
- Приложение не запускает несколько локальных генераций одновременно.
- Последний успешный ответ сохраняется на экране при отмене или ошибке обновления. Если данные поменялись, появляется подсказка обновить совет вручную.

Модель уже установлена на этом Mac. На другом Mac её можно скачать в Настройках → «Помощник без лишней нагрузки» (2,5 ГБ).

## Проверка

85 автоматических тестов прошли. Проверены отсутствие автоматических запусков, повторные нажатия, отмена, запоздалый ответ и сохранение прошлого совета при ошибке.

На Mac M4 / 16 ГБ фактический запрос из сборки 2.3.1 использовал 3 722 602 085 байт по данным Ollama, `size_vram = 0`, контекст 6144. После нажатия «Отмена» список загруженных моделей стал пустым. В предварительном замере этой же модели с контекстом 8192 выборочная нагрузка процесса достигала 200% одного ядра; ответ занял 51 секунду. Это отдельные контрольные прогоны, а не гарантия времени ответа.

В изолированной копии приложения с тестовым дневником получен полный ответ с двумя вариантами ужина. После ввода 300 активных ккал остаток изменился с 2050 до 2350; прежний совет сохранился с отметкой об изменённых данных, повторной загрузки модели не было. Личные записи пользователя не изменялись.

Одновременное воспроизведение видео и звука пока не проверено. CPU-режим всё ещё использует общую память Mac; при большом числе тяжёлых приложений задержки возможны.
