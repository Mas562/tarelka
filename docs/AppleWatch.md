# Apple Watch → iPhone → «Тарелка» на Mac

Всё ниже можно использовать без подписки и платного приложения. На Apple Watch ничего устанавливать не нужно: используются данные, уже попавшие в «Здоровье» на связанном iPhone.

Доступны импорт дневных итогов, показ даты обновления, ручной ввод и автоматическое перечитывание подключённого файла. Прямого сопряжения с часами или автоматического экспорта с iPhone внутри приложения нет. Импорт проверен на тестовых файлах; работу со своим iPhone проверьте первым переносом данных.

## Самый простой способ — AirDrop

1. Откройте «Фитнес» на iPhone. Убедитесь, что сегодняшнее красное кольцо обновилось с часов.
2. Откройте «Здоровье», нажмите изображение профиля → «Экспортировать все данные о здоровье» → подтвердите экспорт.
3. Поделитесь полученным ZIP через AirDrop на свой Mac. Для этого не нужно место в iCloud.
4. Дважды нажмите ZIP в Finder. В распакованной папке `apple_health_export` найдите `export.xml`.
5. В «Тарелке» откройте **Мой день → Импорт с iPhone…** и выберите `export.xml`.
6. Сравните активные калории за тот же день с красным кольцом в «Фитнесе». В течение дня значение относится к моменту экспорта.

Для новых показаний повторите экспорт. Повторный импорт обновляет итог за день, не прибавляет его ещё раз. Более старый экспорт не заменяет более свежую запись.

Приложение читает только `ActivitySummary` — дневные итоги «Подвижности». Пульс, маршруты, сон и другие записи не сохраняются в «Тарелку». Сам экспорт Apple содержит все данные «Здоровья» и остаётся там, куда вы его сохранили. При отсутствии итогов приложение сообщит об этом, а не покажет выдуманный ноль.

## Регулярные обновления через «Команды»

Этот вариант требует разовой настройки и проверки на iPhone. Названия действий могут отличаться в зависимости от языка iOS. «Команды» должны получить разрешение читать активную энергию в «Здоровье». Mac и iPhone должны иметь доступ к одному файлу на iCloud Drive. При заполненном iCloud используйте AirDrop или ручной ввод.

Создайте на iPhone команду со следующей последовательностью:

1. **Текущая дата**: сохраните время запуска, чтобы все следующие действия относились к одному дню.
2. **Найти образцы данных здоровья / Find Health Samples**: тип **Активная энергия / Active Energy (Active Calories)**; дата начала — сегодня; источник — только ваши текущие **Apple Watch**. Отключите ограничение числа результатов. Не выбирайте одновременно iPhone, тренировочные приложения и часы.
3. Если образцов нет, завершите команду без записи файла: отсутствие разрешения или ещё не пришедшие данные не означают нулевой расход.
4. Получите числовые значения энергии найденных образцов в **ккал** и сложите их действием расчёта статистики **Сумма**. Если данные в кДж, переведите их в ккал делением на 4,184. Округлите сумму до целого — это также исключает десятичную запятую в JSON.
5. Из времени запуска получите две строки: дату в пользовательском формате `yyyy-MM-dd` и время в формате ISO 8601 с часовым поясом, **без дробных секунд**. Например: `2026-09-08T18:15:00+05:00`.
6. В действии **Текст** соберите JSON по образцу ниже. Подставьте переменные вместо даты, числа калорий и времени. Число калорий — без кавычек и пробелов-разделителей тысяч.
7. **Сохранить файл** → `iCloud Drive/Shortcuts/tarelka-activity.json`. Выключите запрос места сохранения, включите замену существующего файла.
8. Запустите команду вручную и разрешите чтение данных. Сравните итог за сегодня с «Фитнесом». Существенное расхождение означает, что нужно проверить единицы, источник и временной интервал. Не автоматизируйте неверный итог. Импорт XML использует готовый итог Apple и предпочтительнее, если образцы не удаётся согласовать.
9. На Mac дождитесь загрузки файла из iCloud Drive, затем **Мой день → Подключить файл…**. Выберите `tarelka-activity.json`.
10. После успешной проверки можно создать личную автоматизацию в «Командах», запускающую эту команду в выбранное время. Доступ к «Здоровью» в фоне зависит от блокировки и разрешений iPhone; сначала проверьте выполнение с заблокированным экраном. В приложении всегда видна дата фактически полученных данных.

```json
{
  "version": 1,
  "days": [
    {
      "date": "2026-09-08",
      "active_kcal": 512,
      "updated_at": "2026-09-08T18:15:00+05:00"
    }
  ]
}
```

Это пример формата, а не ваши показания. Команда для iPhone не установлена и не проверена автоматически этим проектом. Первую настройку нужно выполнить на самом iPhone.

«Тарелка» проверяет подключённый файл раз в минуту, пока открыта, и после следующего запуска. В файле может быть один день или несколько; уже полученные другие дни сохраняются. Чтобы не пропускать дни, регулярно запускайте передачу; пропуски можно заполнить экспортом XML. Отключение файла останавливает обновления, но сохраняет историю.

## Что означает расход

Красное кольцо показывает **активную** энергию, без энергии покоя. Это оценка часов. В режиме «Покой + Apple Watch» эти активные калории прибавляются к расходу в покое и увеличивают остаток питания. Коэффициент активности в этом режиме не применяется. Формула: база + активность − поправка на цель − съеденное. Если выбран режим «Обычная активность», движение уже учтено коэффициентом, поэтому часы показаны отдельно. При отсутствии показаний за выбранный день приложение сообщает об этом; данные других дней не подставляются.

Остаток калорий = текущая дневная норма − съеденные за выбранный день калории. Для прошлых дней используется текущая норма. Если остаток отрицательный, приложение показывает величину «Сверх нормы».
